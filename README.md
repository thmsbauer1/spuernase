# Spürnase

Lese-App mit Detektivfällen für die 5. Klasse. Detektivhund Lupo führt durch die Fälle: Philip liest ein Kapitel, beantwortet Fragen zum Text und sammelt Spuren auf der Pinnwand. Am Ende eines Falls erhebt er Anklage und begründet sie mit zwei Spuren.

- Fälle, Kapitel und Fragen stehen in `inhalte.js`. Fragetypen: Fakt, Wort, Schlussfolgern, Beweis (Satz im Text antippen), Reihenfolge.
- Fälle werden der Reihe nach freigeschaltet: Ist ein Fall gelöst, kommt der nächste. Gelöste Fälle bleiben im Archiv.
- Tagesziel (einstellbar unter „Für Eltern“, 1 oder 2 Kapitel) zählt für die Serie. Weiterlesen ist immer erlaubt, jedes weitere Kapitel ist ein Bonus-Kapitel mit Extra-Lupen.
- Stufen: Die Kapitel werden von Fall zu Fall länger (Stufe 1 ca. 250–330 Wörter, Stufe 2 ca. 350–450, später 600 und 1000+). Es gibt keinen Zeitdruck.
- Die Elternansicht zeigt den Vorrat an ungelesenen Kapiteln. Wird er knapp, kommen neue Fälle per Update dazu.
- „Für Eltern“ (unten auf der Startseite) zeigt Lesezeit, Wörter pro Minute und Trefferquote je Fragetyp.
- Läuft im Browser und lässt sich in Chrome über „App installieren“ auf den Startbildschirm legen. Der Fortschritt wird nur auf dem jeweiligen Gerät gespeichert.
